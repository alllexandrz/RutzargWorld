# Редактор речей Rutzarg

Інструмент для дизайнера: речі, рецепти, знаряддя й економіка гри в одному вікні. Чистий TypeScript без фреймворків, інтерфейс у стилі Phaser Editor.

## Запуск

```bash
npm run editor            # зібрати (tools/item-editor/dist)
npm start                 # гра + редактор; редактор — http://localhost:8787/editor/
node tools/item-editor/build.ts --watch   # збирати при змінах
```

Редактор відкривається із сервера гри (`/editor/`) і одразу завантажує речі, з якими гра працює зараз. Без сервера (відкрити `dist/index.html` як файл) працює з вбудованими значеннями та JSON-файлами.

## Доступ (безпека)

- **`ADMIN_EMAILS`** у `.env` — через кому email акаунтів гри, яким дозволено редактор. Тоді `/editor/` і `/api/gamedata` відкриваються **лише після входу** (`/editor/login.html`: email+пароль або Google — той самий акаунт, що й у грі). Звичайний гравець не зайде, навіть якщо знає адресу.
- **`ADMIN_EMAILS` не задано** — редактор працює лише на тому самому комп'ютері, що й сервер (розробка), без входу; ззовні закритий повністю.
- Сесія редактора — у cookie `rz_editor` (HttpOnly, SameSite=Strict, Secure на https, 12 годин). «Вийти» у правому верхньому куті видаляє сесію на сервері.
- Без входу сервер не віддає ні сторінку редактора, ні його скрипт, ні дані гри; запис вимагає ще й заголовка `x-rutzarg-editor` (захист від підроблених запитів з інших сайтів; CORS вимкнено).
- Відповідь на невдалий вхід однакова для «немає акаунта», «невірний пароль» і «не адмін» — не видно, хто адміністратор; спроби обмежені (сервер + nginx).
- **`ADMIN_TOKEN`** (необов'язково) — для скриптів: заголовок `x-admin-token` дає доступ до `/api/gamedata` без входу.
- Хто застосував зміни, пишеться в лог сервера; у хроніку гри (її бачать гравці) email не потрапляє.

## Що вміє

| Панель | Що там |
|---|---|
| **Речі** (ліворуч) | дерево за групами, пошук; позначки «нова», «змін.» (відносно гри), кількість помилок |
| **Граф ремесла** (центр) | ліворуч — з чого робиться (до сировини), праворуч — де використовується; колесо — масштаб, тягни — рух, клік — вибрати |
| **Економіка** | усі рецепти поруч: компоненти, скільки платить ринок, прибуток «купив → зробив → продав» (арбітраж підсвічено), срібло за годину ремесла, «усе сам», «продати сировину» |
| **Добування й знаряддя** | хто чим добувається, хвилин на одиницю, одиниць і срібла за годину, знос знаряддя; знаряддя для роботи на підприємствах |
| **Зміни відносно гри** | поле за полем: що в грі і що в редакторі |
| **Інспектор** (праворуч) | річ (назва, група, колір, об'єкт мапи), ринок (ціна, норма запасу, каравани + діапазон цін, ціна викупу, оптовики), спорядження (слот, атака, захист, вигляд, міцність, бонуси збору, знос і ремонт), добування (якими знаряддями), рецепт (станція-обладнання, навичка, **мінімальний рівень навички**, **інструменти**, час, вихід, компоненти), економіка рецепта (зі зносом інструментів), «де використовується» (і як інструмент) |
| **Проблеми / Журнал** (внизу) | перевірка даних тими самими правилами, що й на сервері; клік — перейти до речі |

Повзунок **«Навичка»** вгорі перераховує час і дохід для рівня навички 0–100.

## Обмін з грою

- **⇣ З гри** — `GET /api/gamedata`: поточні речі, рецепти, правила знарядь і довідники (навички, станції, слоти, об'єкти мапи, константи економіки).
- **⇡ У гру** — `POST /api/gamedata`: сервер перевіряє дані, застосовує одразу (гравці отримують зміни без перезаходу) і зберігає в `data/game-data.json`. Після перезапуску сервер завантажує цей файл поверх вбудованих значень.
- **Відкрити / Зберегти** — той самий формат JSON (`format: "rutzarg-gamedata"`), для версій і обміну.
- **Вбудовані** — значення з коду гри (`shared/items.ts`, `shared/crafting.ts`, `shared/gear.ts`).
- Чернетка автоматично зберігається в браузері; **Ctrl+Z / Ctrl+Shift+Z** — скасувати / повторити, **Ctrl+S** — зберегти файл.

## Обмеження (щоб не зламати живий світ)

- Вбудовані речі не видаляються (на них посилаються код, збереження й мапа) і не змінюють `id`. Нові речі можна створювати, перейменовувати й видаляти.
- Нова річ, що ставиться, має використати наявний об'єкт мапи. Новий одяг чи зброя малюються на персонажі як найближча вбудована річ, поки немає свого спрайта.
- Якщо видалити `data/game-data.json`, нові речі зникнуть із гри, а в сумках і на ринку збереженого світу вони лишаться невідомими. Тому файл з новими речами варто зберігати разом зі світом.

Код: `src/model.ts` (стан, undo/redo), `src/economy.ts` (формули), `src/views.ts` (граф і таблиці), `src/inspector.ts`, `src/outline.ts`, `src/main.ts`. Формат і правила перевірки спільні з грою: `shared/gamedata.ts`.
