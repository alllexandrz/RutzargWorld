# Rutzarg — живий світ (прототип «Каргат»)

AI-driven fantasy life simulator / MMORPG. Концепт: [`docs/Rutzarg_MMO_Concept_v2.md`](docs/Rutzarg_MMO_Concept_v2.md).
Це **перший vertical slice** (розділ 28 концепту): один район міста, ~15 автономних агентів, спільний серверний світ для кількох гравців.

- Прогрес і що зроблено: [`docs/PROGRESS.md`](docs/PROGRESS.md)
- Архітектура: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
- Контракт для майбутніх редакторів анімацій/графіки: [`docs/ART_PIPELINE.md`](docs/ART_PIPELINE.md)

## Швидкий старт

Потрібен **Node.js 22.18+** (рекомендовано 24). Node запускає TypeScript напряму, без компіляції.

```bash
npm install
npm start          # збирає клієнт і запускає сервер на http://localhost:8787
```

Відкрий `http://localhost:8787`, створи акаунт (або «грати як гість»), створи персонажа — і ти у світі.

## Як пограти разом із другом

Сервер один, а гравці підключаються браузером. Світ спільний: ви бачите одне одного, NPC реагують на вас обох.

**1. Одна локальна мережа (Wi-Fi / LAN).** Після `npm start` сервер виводить адресу `LAN: http://192.168.x.x:8787`. Друг відкриває її у своєму браузері. Якщо не відкривається, дозволь Node вхідні з'єднання у фаєрволі macOS.

**2. Через інтернет, найпростіше: тунель.** Сервер і WebSocket працюють на одному порту, тож вистачить одного тунелю:

```bash
# варіант А — Cloudflare (без реєстрації)
brew install cloudflared
cloudflared tunnel --url http://localhost:8787
# → дає https://xxxx.trycloudflare.com — надішли посилання другу

# варіант Б — ngrok
ngrok http 8787
```

Клієнт сам перемикається на `wss://`, якщо сторінку відкрито через https.

**3. Проброс порту на роутері** (TCP 8787 → твій комп'ютер), після чого друг відкриває `http://<твій-публічний-IP>:8787`.

> Сервер — це твій комп'ютер: поки він працює, світ живе (і NPC теж). Світ автоматично зберігається в `data/world.json` щохвилини та при зупинці (Ctrl+C).

## Керування

| Клавіша | Дія |
|---|---|
| WASD / стрілки, клік по землі | рух |
| колесо миші | масштаб |
| клік по персонажу | вибрати (говорити / спостерігати / обікрасти) |
| **E** | взаємодія: розмова з найближчим NPC, ринок або збирання |
| **F** | збирати ресурс (дерево → деревина, рудна скеля → руда, сіра скеля → камінь, трави, поле → зерно) |
| **T** | посадити саджанець (поза містом; виросте в дерево за 3 дні) |
| **Q** | їсти (з сумки або купити миску в таверні) |
| **R** | відпочити (лише в будівлі) |
| **P** | молитися (храм / гай Клумногів) |
| **M** | ринок (на центральній площі) |
| **B** | справи: купити лісопилку (у резиденції старости), платня, каса, звільнення |
| **K** | навички (ростуть від використання) |
| **J** | журнал розмов: усі діалоги з NPC, можна перечитати будь-коли |
| **L** | хроніка світу («істина світу», інструмент спостерігача) |
| **I** | спостерігач: потреби, цілі, характер, стосунки й пам'ять вибраного NPC |
| **Enter** | чат з іншими гравцями |
| **H** | довідка |

Кириличну розкладку теж підтримано (У/А/Й/К/…).

## Що спробувати

- Пиши NPC довільний текст у вікні діалогу (поле внизу, Enter): «Що думаєш про Томаса?», «Де Горст?», «Маєш борги?», «Які ціни на ринку?».
- Розпитай людей у таверні «Що нового?» і «Де …?». Відповіді беруться з **їхньої пам'яті**, не з істини світу, тож можуть бути застарілими або хибними.
- Заробіть 120 срібла (збирання + ринок) і купіть «Стару лісопилку» в резиденції старости **раніше за купця Маркуса**, який теж на неї збирає.
- Найміть NPC («Запропонувати роботу»). Вони зважують платню, довіру й лояльність до нинішнього господаря. Не заплатиш вчасно, і вони підуть.
- Досліджуй велику мапу (мінімапа вгорі праворуч, клік — іти туди): пуща, Заріччя за річкою, діброва, кам'яні пагорби з родовищами.
- Ресурси вичерпуються: зрубане дерево стає пнем, вибрана скеля зникає. Саджай ліс (T). Коли руда й камінь на поверхні закінчуються — місто чи ти (за свої гроші, у «Справах») будуєте шахти й кар'єри на родовищах.
- Стеж за розбудовою: коли населення зростає (переселенці, діти), староста замовляє нові будинки, артіль скуповує деревину, камінь та інструменти на ринку й будує. Продавай їм матеріали, ціни ростуть.
- Закохайся й одружися: компліменти й подарунки піднімають симпатію NPC, потім «Освідчитися», і весілля в Храмі Світанку. Подружжя живе разом, і через 20 ігрових днів після вагітності народжується дитина. NPC теж закохуються й одружуються між собою.
- Спробуйте обікрасти когось. Свідки розкажуть іншим, варта прийде по вас, а жрець перекаже це Клумногу.
- Здобудьте довіру Клумнога **Ваеля** в гаю на південному заході (через південну браму).
- Відкрийте Хроніку (L) і спостерігайте: борги, крадіжки, арешти, переманювання працівників відбуваються без участі гравців.

## Запуск на сервері (Docker)

```bash
cp .env.example .env     # зміни пароль бази
docker compose up -d --build
```

Гра + PostgreSQL (знімки світу, журнал подій, статистика `/api/stats`). Деталі, HTTPS та AI в Docker: [`docs/DEPLOY.md`](docs/DEPLOY.md).

## Опціональний AI (LLM)

Без LLM гра повністю працює на utility AI. Щоб NPC вирішували важливі речі й відповідали на вільні репліки через локальну модель:

```bash
ollama pull gemma3:4b
RUTZARG_LLM=ollama LLM_MODEL=gemma3:4b npm start
# або будь-який OpenAI-сумісний сервер (LM Studio, llama.cpp):
RUTZARG_LLM=openai LLM_URL=http://localhost:1234 LLM_MODEL=<model> npm start
```

## Скрипти

| Команда | Що робить |
|---|---|
| `npm start` | збірка клієнта + запуск сервера |
| `npm run dev` | клієнт у watch-режимі + сервер з автоперезапуском |
| `npm run typecheck` | перевірка типів усього проєкту |
| `npm run sim -- 5` | прогнати 5 ігрових днів без гравців і вивести хроніку (перевірка emergent-поведінки) |
| `node scripts/smoke-test.ts ws://localhost:8787/ws` | мультиплеєрний smoke-тест двома ботами (сервер має бути запущений) |
| `node scripts/auth-test.ts --mock-google http://localhost:8787` | тест акаунтів/сесій/Google OAuth (сервер з `GOOGLE_TOKEN_URL=http://127.0.0.1:9911/token`) |

Змінні середовища сервера: `PORT` (8787), `SAVE_FILE` (`data/world.json`), `FRESH_WORLD=1` (ігнорувати збереження), `START_HOUR` (година старту нового світу, напр. `21` щоб одразу побачити ніч).
