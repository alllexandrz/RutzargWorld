# Графіка та анімації: контракт для редакторів

Уся поточна графіка **процедурна і тимчасова** (`client/src/textures.ts`). Вона генерується при старті в текстури Phaser під фіксованими ключами. Редактори анімацій, тайлів і карт мають видавати дані, які займуть місце цих ключів. Код рендера змінювати при цьому майже не доведеться.

## 1. Ізометрія

- Тайл — ромб **64×32 px** (`TW`, `TH` у `client/src/iso.ts`).
- Світові координати: `x` праворуч-вниз, `y` ліворуч-вниз; центр тайлу `(tx+0.5, ty+0.5)`.
- Глибина малювання: `(x + y) · 10` (+3 для персонажів).

## 3. Персонажі

Спрайтшит персонажа складається з **трьох шарів**, які накладаються один на одного й тонуються кольором конкретного персонажа (`Look` у протоколі):

| Текстура | Тонування |
|---|---|
| `char_body` | `look.body` (одяг) |
| `char_skin` | `look.skin` |
| `char_hair` | `look.hair` |

Кадри мають розмір **32×52**, origin (0.5, 0.92), тобто ноги стоять у точці позиції.
Сітка: 9 кадрів × 2 ряди. Ряд 0 — обличчям до камери, ряд 1 — спиною. Ліво/право отримуємо дзеркаленням.

| Кадр | Значення |
|---|---|
| 0 | idle |
| 1–4 | walk |
| 5–6 | work |
| 7 | sleep (лежить) |
| 8 | pray |

Анімації Phaser мають ключі `{layer}_{row}_{anim}`, де `anim ∈ idle | walk | work | sleep | pray`.
Серверний стан `Anim` (`shared/protocol.ts`) відображається в анімацію функцією `mapAnim()` у `WorldScene.ts`.

## 4. Як підключити дані з редактора (план)

1. Редактор експортує PNG-атлас + JSON (формат Phaser `atlas` або власний) з тими самими ключами кадрів чи анімацій.
2. У `WorldScene` додати `preload()`, який вантажить `client/public/assets/*`. `generateTextures()` вже пропускає ключі, які існують (`canvasTex` перевіряє `textures.exists`). Тому достатньо **завантажити файли раніше**, і процедурна графіка автоматично замінюється.
3. Анімації з редактора (кадри, тривалість, події на кадрах) можна описувати JSON-ом `{ key, frames:[{key,frame,duration}], repeat }` і реєструвати через `anims.create` перед `makeCharacters`.
4. Для 8-напрямкових спрайтів пізніше варто розширити `EntityView.apply()` з 2 рядів до 8 (індекс `f` з протоколу вже має 8 напрямків).
